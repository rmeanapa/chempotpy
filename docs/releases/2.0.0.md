# ChemPotPy 2.0.0

ChemPotPy 2.0 is the first release of the self-contained, modernized PES
library maintained by Ruben Meana-Paneda. It preserves the scientific models
and citations of the original ChemPotPy project while rebuilding their shared
software infrastructure and validation.

## Highlights

- **404 callable surfaces across 100 chemical systems.** The catalog includes
  single-state and multistate PESs, diabatic matrices, gradients, and
  nonadiabatic couplings.
- **Self-contained evaluations.** Published fit constants, neural-network
  parameters, and model data are embedded with their owning surface; runtime
  evaluations do not depend on external parameter files.
- **Modern Fortran sources.** The catalog uses explicit typing, module-owned
  state, private-by-default APIs, structured control flow, and a shared core
  for kinds, constants, units, geometry, linear algebra, interpolation, neural
  networks, and dispersion.
- **Standalone export.** Any catalog entry can be exported as one
  dependency-complete `.f90` source, optionally with a runnable example that
  reports energies and finite-difference gradients and Hessians.
- **Catalog-wide regression testing.** Nine deterministic geometries per
  surface are checked on Linux and macOS, alongside strict compilation,
  extension-import, standalone-export, and modernization gates.
- **A simpler contribution route.** Scientists can submit legacy source,
  parameters, references, and known results through the
  [new PES form](https://github.com/rmeanapa/chempotpy/issues/new?template=new-pes.yml).
  No Git workflow or source modernization is required from the submitter.

## Install from source

```bash
git clone https://github.com/rmeanapa/chempotpy.git
cd chempotpy
conda env create --file environment.yml
conda activate chempotpy
python -m pip install -e .
make build BUILD_FLAGS="--jobs 4"
```

## Compatibility

The public Python boundary continues to use Cartesian coordinates in angstrom,
energies in electronvolt, gradients in eV/angstrom, and nonadiabatic couplings
in 1/angstrom. See the [PES contract](../PES_CONTRACT.md) and
[modernization record](../MODERNIZATION.md) for detailed compatibility and
validation decisions.

Adding a potential energy surface
=================================

The supported interface and modernization rules are defined in
`docs/PES_CONTRACT.md` and `docs/FORTRAN_STYLE.md`. New surfaces must follow
those documents instead of the removed legacy metaprogramming workflow.

1. Add one independent Fortran module under `chempotpy/<system>/`.
2. Expose only the standard `pes` or `dpem` entry point required by the Python
   adapter. Keep implementation procedures and immutable parameters private.
3. Put reusable numerical operations and physical constants in `chempotpy/core`.
4. Do not read model parameters at run time. Embed released parameters in the
   owning PES module or a generated, PES-specific parameter module. Preserve
   the released files only under `tests/data` when they are needed to verify
   the generated source.
5. Register support sources in `scripts/build_pes.py`; do not add one-off build
   scripts or hard-coded shared-library paths.
6. Add catalog metadata and a numerical reference case, then update the
   registry, contract, standalone-export, formatting, compilation, and
   all-surface regression tests.
7. Run the validation commands documented in `README.md` before submitting the
   change.
